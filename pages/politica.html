Política de Privacidade

1. Sobre o Promptica

O Promptica é uma extensão de navegador desenvolvida com o objetivo de auxiliar usuários na criação de prompts para ferramentas de Inteligência Artificial, oferecendo uma interface guiada baseada em princípios de engenharia de prompt e Interação Humano-Computador.

2. Informações coletadas

2.1 Dados fornecidos pelo usuário

Nome e e-mail (quando o usuário realiza login);

Prompts criados pelo usuário;

Preferências da aplicação;

Histórico de prompts.

2.2 Dados armazenados localmente

A extensão utiliza:

localStorage

chrome.storage.local

Esses recursos armazenam:

histórico de prompts;

configurações da interface;

informações temporárias da sessão;

dados necessários para funcionamento da aplicação.

2.3 Dados de autenticação

Caso o usuário utilize login via Google ou autenticação por e-mail, informações básicas de perfil podem ser armazenadas para identificação da conta.

3. Como as informações são utilizadas

As informações coletadas são utilizadas exclusivamente para:

funcionamento da extensão;

armazenamento e recuperação de prompts;

autenticação do usuário;

sincronização de dados;

personalização da experiência;

melhoria contínua da aplicação.

O Promptica não vende, compartilha ou comercializa dados pessoais dos usuários.

4. Integração com serviços de terceiros

O Promptica pode utilizar serviços externos para funcionamento de determinadas funcionalidades, incluindo:

4.1 Supabase

Utilizado para:

autenticação;

armazenamento de perfis;

persistência remota de prompts.

4.2 APIs de Inteligência Artificial

A extensão pode realizar requisições para APIs externas de IA com a finalidade de:

gerar prompts;

refinar instruções;

auxiliar na construção textual.

As informações enviadas para essas APIs dependem exclusivamente do conteúdo inserido pelo usuário.

5. Segurança das informações

O Promptica adota medidas razoáveis para proteger os dados dos usuários, incluindo:

uso de HTTPS em requisições;

armazenamento modularizado;

controle de permissões da extensão;

restrições de Content Security Policy (CSP);

autenticação segura via serviços externos.

Apesar disso, nenhum sistema é completamente seguro, e não podemos garantir segurança absoluta contra acessos não autorizados.

6. Permissões da extensão

A extensão pode solicitar permissões como:

storage — para salvar dados localmente;

identity — para autenticação do usuário;

acesso a APIs externas necessárias para funcionamento.

Essas permissões são utilizadas exclusivamente para funcionalidades internas da aplicação.

7. Direitos do usuário

O usuário pode, a qualquer momento:

excluir prompts armazenados;

remover dados locais;

encerrar sessão da conta;

desinstalar a extensão;

solicitar remoção de dados armazenados remotamente.

8. Retenção de dados

Os dados permanecem armazenados:

localmente, enquanto a extensão estiver instalada;

remotamente, enquanto a conta do usuário permanecer ativa.

O usuário pode remover seus dados manualmente a qualquer momento.

9. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada periodicamente para refletir melhorias, mudanças legais ou novas funcionalidades. Recomendamos a revisão periódica deste documento.

10. Contato

Em caso de dúvidas, sugestões ou solicitações relacionadas à privacidade, entre em contato através dos canais disponibilizados na aplicação.

11. Consentimento

Ao utilizar o Promptica, o usuário declara estar ciente e de acordo com os termos desta Política de Privacidade.
